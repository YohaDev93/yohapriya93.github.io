# Yohapriya Vairaperumal - Portfolio

## Publish on GitHub Pages
1. Upload `index.html`, `styles.css`, and `script.js` to the root of your `YOURUSERNAME.github.io` repository.
2. Go to Settings → Pages.
3. Select Deploy from a branch.
4. Select `main` and `/(root)`.
5. Save and wait for deployment.

## Important
In `index.html`, replace the generic LinkedIn URL with your real LinkedIn profile URL.
